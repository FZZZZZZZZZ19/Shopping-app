Shopping APP 1.1.0（versionCode 2），支持 Android 8.0+，与 1.0 同包名、同试用签名，可直接覆盖升级。

- 搜索改为四平台并行加载与同一商品列表，不再先选择单个平台。
- 商品卡显示页面读取到的商品标题、平台、店铺、价格和读取时间；支持价格升序/降序及平台筛选。
- 增加官方网页登录入口，登录与 Cookie 留在本机。需要验证码时由用户在官方页面完成。
- 增加关键词/型号/容量筛选，明确区分同款候选、页面价和起价；保留旧版收藏和手动报价本。

**此版为网页登录页面采集兼容模式，不是平台授权 API。必须在应用内登录；平台限制、验证码、页面布局或字段缺失仍可能导致某个平台没有结果。缺失店铺名不会补造。不能保证四平台均成功返回；真实账号登录后的完整结果仍需在手机上验证。**

排序使用搜索页展示价，不代表已选择相同 SKU 的最终结算价。请核对型号、容量、颜色、优惠条件与运费。

四平台解析和聚合排序的自动化测试使用测试 HTML，生产 APK 不包含演示报价或测试商品。完整源码已补齐到 [main 分支](https://github.com/FZZZZZZZZZ19/Shopping-app)，也可下载本 Release 的 [完整源码包 shopping-app-1.1.0-source.zip](https://github.com/FZZZZZZZZZ19/Shopping-app/releases/download/v1.1.0/shopping-app-1.1.0-source.zip)。原 v1.1.0 标签自动生成的 Source code 压缩包仍为旧提交快照，请使用上述完整源码包。
