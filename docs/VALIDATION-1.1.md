# 1.1.0 验证记录

日期：2026-11-09。构建工具与旧版一致：Gradle 8.9、AGP 8.7.3、JDK 21、Android SDK 35。

- versionName `1.1.0`、versionCode `2`、包名 `com.shopping.app`。
- 1.0 与 1.1 的签名证书 SHA-256 一致：`b220109e82b3c3e2e99589bdf7c7b1cc7b7782190899d0354c8f2d5168d6b7a7`。
- Java 单元测试覆盖金额、URL、不同型号/容量过滤、平台筛选、价格升降序、最新报价去重及缺失字段。
- 10 项 DOM 测试覆盖四平台商品卡、PDD 公开 CSS-module 布局、JSON-LD、店铺未知、分期/优惠券误识别、跨商品价格混淆、登录/验证码和空页面。
- Android 设备测试包含原有 9 项数据检查，以及实际 WebView 页面经过脚本采集进入原生列表、四平台与店铺字段、价格升降序、平台过滤、登录过期状态。

以上四平台自动化测试使用测试包中的 HTML 测试页面，不使用真实账号或真实商品价格；测试页面不会进入生产 APK。未完成真实四平台账号登录后的真机端到端验证，不能把测试通过解读成四个平台必然可用。

当前云环境的淘宝/天猫页面代理访问受限，京东搜索会跳转风控页，拼多多返回动态加载页面。因此发布说明保留登录、验证码与网页布局兼容限制，不宣称已验证实时全平台价格。

19 项 Java 单元测试、10 项 DOM 测试、5 项聚合设备检查均通过，Android Lint 无问题。

设备检查使用 Android 9 / API 28，系统 WebView 66。先前运行中的旧功能前 9 项检查通过；聚合检查发现测试 HTML 被标为 about:blank，以及 Android ICU 不支持 IsHan 正则两项问题，均已修复。修复后的独立聚合设备检查通过，记录见 `aggregate-device.txt`；先前日志保留在 `legacy-and-initial-aggregate.txt`，不将其失败的整次运行统计为通过。

1.0 覆盖升级到 1.1 已实际安装成功，升级前后本地 SharedPreferences 文件逐字节一致。所有结果保存在 `docs/test-results/1.1/`。
