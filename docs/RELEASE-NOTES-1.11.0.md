Shopping APP 1.11.0（versionCode 3），支持 Android 8.0+。

**签名变更（重要）**：1.11.0 起改用正式发布证书，与 1.1.0 的试用签名不同。已安装 1.1.0 或更早版本的用户无法直接覆盖升级，需要先在“我的”导出 JSON 备份，再卸载旧版、安装 1.11.0，最后导入备份。卸载会清除本机收藏、报价和搜索历史。从 1.11.0 开始，后续版本可以直接覆盖升级。

新增：

- “我的”页新增“检查更新”：直连 GitHub Releases，读取最新版本、发布说明和 APK 大小。
- 发现新版本后可应用内下载，并拉起系统安装器；首次安装需要允许“Shopping APP”安装未知应用。
- 检查失败时可直接打开 GitHub Release 页面手动下载。
- 版本号统一来自 `BuildConfig.VERSION_NAME`，不再散落在界面代码里。

限制：

- GitHub API 未登录时每 IP 每小时 60 次请求；超过后会提示稍后再试。
- 应用内更新只接受 GitHub Release 中名称以 `.apk` 结尾的附件；不读取平台商品数据。
- 四平台网页采集的限制与 1.1.0 相同：不是授权 API，登录、验证码、页面布局变化仍可能导致某个平台没有结果。
- 排序使用搜索页展示价，不代表同一 SKU 的最终结算价。
