Shopping APP v1.0.0，支持 Android 8.0 及以上版本。

- 淘宝、拼多多、京东、天猫官方网页搜索与平台切换。
- 店铺收藏、编辑、删除及平台筛选。
- 手动记录商品价格、运费和优惠，按相同商品规格分组排序。
- 本地搜索历史、JSON 数据备份与恢复。

**价格说明：本版本没有接入平台授权价格 API。平台网页显示的价格由平台提供；比价本的价格由用户手动填写，不会自动同步。网页可能需要登录、验证码或外部打开。**

APK 使用调试签名，供直接安装试用；正式应用商店发行应使用你自己的发布证书。附件提供 APK 与 SHA-256 校验文件。
